Autheniccation REST API 

What i implemented is 
1)user registration and login  
2)Password hashing using bcrypt 
3)Jwt-based authentication
4)protected API routes 
5)request validation 
6)rate limiting with 429 too many requets
7) MongoDB database integration using mongoose 
8) Environment variables usign .env file 
9) CORS configuration

Security features
1) Passwords are never stored in plain text
2) JWT is verified before accessing protected routes
3) Rate limiter prevents excessive API requets
4) sensitive configuration is stored in environment variables
